# Техническое задание: Saby Stats Report

Версия документа соответствует расширению **1.2.0**.

## 1. Назначение

Chrome MV3-расширение для внутренних стендов статистики Saby. Пользователь один раз копирует **плоский JSON фильтра из UI статистики**, дальше меняет только период в расширении и получает PDF-отчёт. Ходить на cloud за новым фильтром при смене дат не требуется.

## 2. Бизнес-процесс

1. На стенде статистики настроить срез (куб, измерения, метрики).
2. Скопировать JSON фильтра из интерфейса (не полный `GetReport` из DevTools).
3. В расширении сохранить фильтр под именем (вкладка «Фильтры»).
4. Синхронизировать стенд (логин/пароль, `SAP.Authenticate`).
5. На вкладке «Отчёт» выбрать стенд, сохранённый фильтр и период.
6. Получить отчёт и при необходимости скачать PDF.

Повторный заход в cloud нужен только если изменилась **структура** отчёта (другие измерения, метрики, `timeStep`), а не даты.

## 3. Стенды

Только:

| id | Хост |
|----|------|
| fix | fix-cloud.sbis.ru |
| test | test-cloud.sbis.ru |
| pre-test | pre-test-cloud.sbis.ru |

Стенд `pre-cloud.sbis.ru` не используется. Auth: `POST /auth/service/?id=1&protocol=7`, метод `SAP.Authenticate`. Отчёт: `POST /stats-cloud-interface/service/?id=1&protocol=7`, метод `CommonStatistic.GetReport`. Fallback URL с `&srv=1` при HTTP 405. Запросы из service worker, `credentials: include`.

## 4. Формат фильтра (требования к JSON)

Пользователь вставляет объект UI, например:

- `cube` — строка (для эталона: `"Вызовы"`);
- `displayType` — `"Таблица"`;
- `version`, `comparePeriodEnabled`;
- `characteristics` — массив `{ id, order?, range? }`;
- `dimensions` — **плоский** массив `{ id, isAggregated, isTimeDim, top, values, excluded, mode, timePeriod, timeStep }`;
- `period` — игнорируется при запросе (подменяется полями отчёта).

**Запрещено для поддержки:** вложенные группы (`__group_0__` как смысловая иерархия). Поля дерева `parent`, `node`, `nodeType`, `hasChildren` допускаются и при сборке RPC игнорируются.

Типовой рабочий срез: агрегированный метод (`Метод_Метод` + `top`) и измерение `time` (`timeStep`: `ten_minute` / `day`, `mode`: `all_days`, `timePeriod` часы суток).

Не вставлять полный jsonrpc `CommonStatistic.GetReport`.

## 5. Компиляция UI-JSON → GetReport

Расширение собирает `params` по эталону протокола 7:

- UI-фильтр (`f: 1`): TZ, characteristics, comparePeriodEnabled, cube, dimensions, displayType, period, version. **Без `idParent`.**
- Списки `values` / `excluded` / `isAggregated` / `top` — в выборке `dimensions`.
- Legacy-фильтр (`f: 5`): вертикальная детализация, время/даты строками (Москва), куб, характеристики для анализа.
- Вертикаль (`f: 6`): слот на каждый `dimensions[].id` из JSON.
  - агрегированное не-time измерение (`isAggregated: true`, обычно метод) — Position/Top (`f: 8`), строки отчёта как «Метод БЛ (Топ N)»;
  - `time` с `isAggregated: true` — запись шага времени (`f: 8`: Filter / FilterDays / FilterHours); иначе пустой слот. Нельзя слать time-запись, если группировка по методу — иначе сервер вернёт итоги по дням.
  - остальные измерения — пустая запись `f: 7`.
  Списки `values` (ответственные и т.п.) — в выборке UI `dimensions`.
- Характеристики для анализа (`f: 9`): слот на каждую метрику; при `order: "desc"` — `{ Top: true }` (`f: 10`), иначе пусто (`f: 7`).
- Навигация: размер страницы 50, до 40 страниц.

Период в RPC: `YYYY-MM-DD HH:mm:ss+03` и legacy `ДД.ММ.ГГ` / `ЧЧ:ММ` (Москва). Календарные `values` у измерения `time` сбрасываются.

## 6. Период в UI

Три режима (сохраняются в `chrome.storage`):

| Режим | Поведение |
|--------|-----------|
| 24 часа | `end = сейчас`, `start = end − 24ч` в момент нажатия «Получить отчёт» |
| 72 часа | то же для 72 часов |
| вручную | поля datetime-local (Москва); показываются только в этом режиме |

Пресеты не подставляют `period` из сохранённого JSON.

## 7. Отчёт и PDF

Таблица: без служебных колонок дерева (`idParent*`, `dimension`, `name0`, `label`). Заголовки: Метод / Ответственный / метрики. Имя файла: `{имя фильтра} ({standId}) ДД-ММ-ГГ.pdf`.

## 8. Нефункциональные ограничения

- Нужны VPN / внутренний DNS до `*.sbis.ru`.
- Пароль хранится в `chrome.storage.local` (без шифрования).
- Длинный период + `ten_minute` увеличивает время расчёта на сервере; клиент не режет период на куски.
- Потолок выборки: 2000 строк (40×50).
