# Инструкция: Saby Stats Report

## Установка

1. Откройте Chrome → `chrome://extensions`.
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → папка `extension/` этого репозитория.
4. После обновления файлов нажмите **Reload** у карточки расширения.

Нужен доступ к внутренним стендам (VPN / корпоративный DNS).

## Один раз: стенд

1. Значок расширения → вкладка **Стенды**.
2. Логин и пароль для FIX / TEST / PRE-TEST.
3. **Синхронизировать** — должна появиться отметка, что сессия есть.

Не используйте стенд pre-cloud.

## Один раз: фильтр (не на каждый отчёт)

1. В UI статистики Saby настройте таблицу (например метод + шаг времени 10 минут).
2. Скопируйте **JSON фильтра** из интерфейса — объект с `cube`, `dimensions`, `characteristics`. Это не огромный запрос из вкладки Network.
3. В расширении вкладка **Фильтры**: имя → вставьте JSON → **Сохранить фильтр**.

Эталон структуры: https://fix-go.saby.ru/sc3.NncKre

Дальше на cloud **не заходите ради смены дат**. Туда нужно возвращаться, только если меняете сам срез (другие колонки, измерения, шаг времени).

Если в cloud выбраны ответственные (чипы), в JSON у `Метод_Ответственный` должен быть массив `values` с этими ФИО. Иначе сервер не режет список и в отчёт попадут все.

## Каждый отчёт

1. Вкладка **Отчёт**.
2. Стенд и сохранённый фильтр.
3. Период (время Москвы):
   - **24 часа** — последние сутки на момент кнопки «Получить отчёт»;
   - **72 часа** — последние трое суток;
   - **вручную** — свои начало и конец (поля появятся на экране).
4. **Получить отчёт**.
5. **Скачать отчёт** — PDF. Имя файла: название фильтра, стенд, дата.

В статусе видно интервал, который ушёл в запрос (`…+03`).

## Если что-то пошло не так

- «Нет ответа от background» — Reload расширения на `chrome://extensions`.
- Ошибка авторизации — снова **Синхронизировать** стенд.
- Пустой отчёт — проверьте период в статусе; на широком окне и шаге 10 минут расчёт на сервере может быть долгим.
- После обновления расширения всегда Reload.
