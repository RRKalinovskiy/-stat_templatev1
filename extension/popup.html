Saby Stats

Логин и пароль для SAP.Authenticate. Запросы идут через текущее подключение (VPN / внутренний DNS).

Фильтр копируется из UI статистики один раз и хранится здесь. На cloud за датами возвращаться не нужно — период задаётся на вкладке «Отчёт».

Формат: плоский JSON (cube, dimensions, characteristics, displayType). Без вложенных групп. Пример среза: метод + time с шагом 10 минут. Служебные поля дерева (parent, node) можно оставить — в RPC они не уходят.

Ссылка на эталонный отчет: https://fix-go.saby.ru/sc3.NncKre

Период считается в момент запроса (время Москвы). «24 часа» и «72 часа» — скользящее окно до текущего момента. «Вручную» — свои начало и конец.
